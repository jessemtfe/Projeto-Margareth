# EcoCat — Evidências de teste e demonstração

## Checklist de captura

Guardar capturas de tela sem nomes, e-mails, tokens, cookies ou dados de acesso:

- [ ] Cadastros de gerador e cooperado.
- [ ] Tabela de preços por competência.
- [ ] Cargas com etapas e alerta dos três rejeitos consecutivos acima de 25%.
- [ ] Registro de turno e demonstração de turno aberto.
- [ ] Produção por material.
- [ ] Prévia mensal com detalhes de preços e produção.
- [ ] Memória individual e cálculo das parcelas.
- [ ] Tentativa bloqueada de fechamento com inconsistência.
- [ ] Período fechado e preço bloqueado.
- [ ] Histórico preservado após recarregar a página.

## Regras para coletar evidências

1. Usar ambiente ou banco de demonstração separado do banco operacional compartilhado.
2. Usar identidades e dados estritamente fictícios; ocultar informações pessoais na captura.
3. Não incluir `.env`, URL de conexão, senha, cookie, token ou tela de configuração da hospedagem.
4. Registrar para cada evidência o cenário, data, ambiente e resultado observado.
5. Capturar resultados reais; este repositório não contém capturas artificiais.
